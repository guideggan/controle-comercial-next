    ENTRADA (ComissaoInput) — tudo explícito, sem query escondida, sem Date.now():
      - colaboradorId: string
      - mesReferencia: string ("YYYY-MM-01")
      - plano: { tipo, config } (a MESMA união discriminada de planos-comissao.schemas.ts:
        planoConfigSchema / PlanoConfig) — reutilizar o TYPE inferido, não redefinir a forma
      - valorRecebidoNoMes: number (já agregado por agregarRecebidoNoMes da Fase 4; NUNCA TCV)
      - percentualAtingimento?: number (fração; 1 = 100%) — usado só por progressivo_atingimento;
        default 0 quando ausente (Meta = Fase 6, ainda não existe — ponto de integração pluggable)
      - numeroCallsRealizadas?: number — usado só por por_calls; default 0 quando ausente
        (Agendamentos = Fase 7, ainda não existe — ponto de integração pluggable)

    SAÍDA (ComissaoResultado):
      - valorBase: number (valorRecebidoNoMes, ou numeroCallsRealizadas quando tipo=por_calls)
      - percentualAplicado: number | null (null quando por_calls)
      - valorComissao: number (arredondado UMA vez, 2 casas)
      - detalhamento: Record<string, unknown> (ex.: faixa escolhida, para o extrato/COMIS-07)

    money.ts:
      - toDecimal(n): Decimal — wrapper decimal.js
      - arredondar(d: Decimal): number — ARREDONDAMENTO ÚNICO, round-half-up (ROUND_HALF_UP,
        casando com ARRED do Excel), 2 casas. É a ÚNICA função de arredondamento; todos os
        cálculos rodam em Decimal e só chamam arredondar() no total final (COMIS-03).

    engine.ts — calcularComissao(input): despacha por input.plano.tipo em um switch
      (Anti-Pattern 4 de ARCHITECTURE.md: dispatch, nunca if/else aninhado), chamando
      uma função por tipo. Cada função pura importa money.ts.

    REGRAS POR TIPO:
      percentual_fixo: valorComissao = arredondar(Decimal(valorRecebido) * percentual)
        percentualAplicado = config.percentual
      progressivo_atingimento: escolhe a faixa cujo deAtingimento é o maior <= percentualAtingimento
        (faixas já vêm ordenadas crescentes por deAtingimento — ver schema); se percentualAtingimento
        < a menor faixa, aplica a primeira faixa (deAtingimento costuma começar em 0).
        valorComissao = arredondar(Decimal(valorRecebido) * percentualDaFaixa); detalhamento inclui a faixa.
      fixo_variavel: valorComissao = arredondar(Decimal(valorFixo) + Decimal(valorRecebido) * percentualVariavel)
        (soma antes de arredondar — arredonda UMA vez no total). percentualAplicado = percentualVariavel.
      por_calls: valorBase = numeroCallsRealizadas; percentualAplicado = null;
        valorComissao = arredondar(Decimal(numeroCallsRealizadas) * valorPorCall). NÃO é % sobre venda.

    Cases (input -> valorComissao) — EXEMPLOS REAIS DAS PLANILHAS, DEVEM BATER AO CENTAVO:
