  <name>Task 1: Client component de pagamento de parcela (marcar pago / reverter)</name>
  <files>src/app/(admin)/vendas/[id]/parcela-pagamento-form.tsx</files>
  <action>
    Criar `parcela-pagamento-form.tsx` ("use client"), seguindo o padrão EXATO
    de venda-form.tsx (react-hook-form + `zodResolver(marcarParcelaPagaSchema)` +
    `toast` do sonner + `useRouter().refresh()` após sucesso; Dialog para o form).

    Props: `{ parcelaId: string; valorPrevisto: number; status: "PENDENTE" |
    "PAGO"; bloqueado: boolean }`.

    Comportamento:
    - Se `status === "PENDENTE"`: botão "Marcar como pago" que abre um Dialog com
      dois campos:
        * `valorRecebido` (Input number) — defaultValues pré-preenchido com
          `valorPrevisto` (regra do domain detail: default = valorPrevisto).
        * `dataPagamento` (Input type="date") — default hoje em "YYYY-MM-DD"
          (montar via componentes UTC de `new Date()` — NUNCA
          `toISOString` dependente de fuso que possa cair no dia anterior;
          usar `getFullYear/getMonth/getDate` locais para o "hoje" que o admin
          enxerga, formatando YYYY-MM-DD, é aceitável para input de data que o
          usuário confirma). No onSubmit chamar
          `marcarParcelaPagaAction(parcelaId, { valorRecebido, dataPagamento })`;
          em sucesso: toast de sucesso + fechar dialog + `router.refresh()`; em
          erro: toast com a mensagem do erro (ex.: mês fechado).
    - Se `status === "PAGO"`: botão "Reverter para pendente" que chama
      `reverterParcelaPendenteAction(parcelaId)` (com um AlertDialog de
      confirmação OU confirmação simples inline — manter simples: botão direto
      com toast); em sucesso: toast + `router.refresh()`.
    - Se `bloqueado === true` (venda fechada): os botões ficam `disabled` (a
      trava real é no service, isto é só UX — mesmo espírito do modo bloqueado do
      venda-form).

    Valor digitado é number puro (sem formatação); a conversão de exibição
    pt-BR NÃO acontece aqui (só no display da tabela via formatarBRL).
  </action>
  <verify>`rtk tsc` sem erros; `rtk lint` sem violações novas; grep confirma import de marcarParcelaPagaAction e reverterParcelaPendenteAction.</verify>
  <done>Componente marca pago (valorRecebido default=valorPrevisto + dataPagamento) e reverte; desabilita quando bloqueado; usa toast + router.refresh.</done>
